MP3 팟캐스트

내 MP3 폴더를 팟캐스트처럼 듣는 아이폰 · 아이패드 앱입니다.

앱 소개

파일 앱의 폴더(iCloud Drive, NAS에서 받은 폴더 등)를 연결하면 폴더 하나를 팟캐스트 하나로 묶어 보여 줍니다. 이어 듣기, 건너뛰기, 재생목록, 잠자기 타이머, 백그라운드 재생, 홈 화면 위젯을 지원합니다. 공개 팟캐스트를 검색해 구독하면 새 에피소드를 받아 같은 폴더에 저장합니다.

기기 간 이어 듣기: 구글 드라이브나 파일 앱 폴더를 골라 아이폰과 아이패드의 재생 위치 · 재생목록을 맞춥니다.

개인정보처리방침

시행일: 2026년 11월 2일

  • 개발자는 사용자 정보를 모으지 않습니다. 개발자는 회원 가입이나 사용자 데이터를 보관하는 서버를 운영하지 않으며, 사용자의 파일, 글, 사용 기록을 개발자에게 보내지 않습니다.
  • 데이터는 기기에 저장됩니다. 연결한 폴더, 재생 위치, 재생목록은 기기 안에만 저장됩니다. 연결한 폴더의 파일은 복사하지 않고 원래 자리에서 읽습니다.
  • 팟캐스트 검색 · 구독. 팟캐스트를 검색하면 검색어가 Apple(iTunes 검색)과 Podcast Index로 보내집니다. 구독한 팟캐스트의 피드와 에피소드 파일은 해당 팟캐스트 제공자의 서버에서 직접 내려받으며, 제공자는 일반 웹 접속처럼 IP 주소를 기록할 수 있습니다.
  • 기기 간 이어 듣기는 선택 기능입니다. 파일 앱 폴더를 고르면 그 폴더에, 구글 드라이브를 고르면 아래와 같이 재생 위치 · 재생목록 파일이 저장됩니다.
  • 구글 드라이브 연결은 선택 기능입니다. 사용자가 설정에서 구글 계정을 연결했을 때만, 재생 위치 · 재생목록 파일이 사용자 본인의 구글 드라이브 "PodPlayer" 폴더에 저장됩니다.
  • 드라이브 접근 범위는 앱이 만든 파일로 한정됩니다. MP3 팟캐스트는 "이 앱이 만든 파일만" 볼 수 있는 권한(drive.file)을 요청합니다. 드라이브의 다른 파일은 읽거나 바꿀 수 없습니다. 연결된 계정을 화면에 표시하기 위해 계정의 이메일 주소를 확인하며, 이 주소는 기기에만 저장됩니다.
  • 로그인 정보는 기기에만 있습니다. 구글 로그인은 구글의 로그인 화면에서 이뤄지며 앱은 비밀번호를 받지 않습니다. 다시 로그인하지 않게 해 주는 토큰은 기기의 키체인에 저장되고, 구글과 통신할 때만 쓰입니다.
  • 연결은 언제든 끊을 수 있습니다. 앱의 설정에서 연결을 끊으면 기기의 토큰이 지워지고 구글에 권한 회수를 요청합니다. 구글 계정의 권한 페이지에서도 직접 회수할 수 있습니다. 드라이브에 저장된 파일은 사용자가 직접 지울 수 있습니다.
  • Google API 서비스 사용자 데이터 정책을 따릅니다. Google API에서 받은 정보의 사용은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 지킵니다. 받은 정보는 위 기능에만 쓰고, 다른 사람에게 넘기거나 광고에 쓰지 않습니다.
  • 광고 (Google AdMob). 앱 안 일부 화면에 Google AdMob 광고가 나옵니다. 광고를 보여 주고 성과를 재기 위해 Google이 기기 정보(기기 종류, OS 버전, IP 주소와 이를 통한 대략적인 위치), 앱별 식별자, 광고를 보거나 누른 기록을 수집할 수 있습니다. 앱은 추적 허용(App Tracking Transparency)을 요청하지 않으므로, 다른 회사의 앱·웹사이트와 묶어 추적하는 데 쓰이는 광고 식별자(IDFA)는 넘어가지 않습니다. Google이 정보를 쓰는 방식은 Google 파트너 사이트 정책과 Google 개인정보처리방침을 따릅니다.
  • 방침이 바뀌면 이 페이지에 시행일과 함께 알립니다.
